### What I'm building now

**[faceless-youtube-automation](https://github.com/ahmadvahidi/faceless-youtube-automation)** — a channel that produces and uploads its own videos.
Trend discovery → LLM script → free TTS voiceover → cinematic motion rendering → Telegram review →
YouTube upload. Python, ffmpeg, YouTube Data API, running unattended on a VPS.

**[NameScout](https://github.com/ahmadvahidi/NameScout)** — find a person's footprint across
Instagram, TikTok, GitHub, YouTube, Twitch, Pinterest and Linktree from a name or username.

**[telegram-to-youtube-uploader](https://github.com/ahmadvahidi/telegram-to-youtube-uploader)** —
Telegram channel → YouTube, with captions, titles and tags handled automatically.

**[youtube-summary-bot](https://github.com/ahmadvahidi/youtube-summary-bot)** — drop a YouTube
link in Telegram, get a summary in your own language, generated by a local model.
